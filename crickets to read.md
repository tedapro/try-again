# Diet and weight change

This project analyses how diet affects weight change using plots, linear models, ANOVA and t-tests.

## How to run
1. Keep `Santori_Wt_Change.csv` and `Git and stuff.Rmd` in the same folder.
2. Install the required packages in R:
   install.packages(c("car", "GGally", "performance", "infer", "tidyverse"))
3. Open `Git and stuff.Rmd` in RStudio and run all code chunks from top to bottom.
